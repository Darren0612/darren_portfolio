# Darren Gunawan — Data Analyst Portfolio

Portfolio data analyst berisi studi kasus analisis data end-to-end dengan Python dan Power BI.

## Project
1. **Analisis penjualan toko perlengkapan rumah tangga di Shopee** (`projects/shopee-sales.html`)
   Data asli 2.772 pesanan Juli–September 2026: tren penjualan, waktu tersibuk, produk andalan, profil pembeli, pembelian ulang, dan retur.
2. **Funnel dan cohort analysis** (`projects/funnel-cohort.html`)
   Funnel pendaftaran siswa education startup dan retention user fintech.

## Struktur folder
```
index.html                  Halaman utama (profil, project, tentang, keahlian, kontak)
projects/                   Halaman studi kasus
assets/css/style.css        Tampilan website
assets/img/                 Grafik notebook dan screenshot dashboard

```

## Privasi data
Data penjualan Shopee sudah dianonimkan: nama, nomor telepon, alamat, nomor resi, dan username pembeli dihapus atau diganti ID anonim sebelum dianalisis.
